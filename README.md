# Weiss Color — проект интернет-магазина

Интернет-магазин красок, лаков и пропиток **Weiss Color** на WordPress + WooCommerce.
Продавец — ООО «Фаер Гвард». Субподряд через агентство (RUSO, договор №24 от 17.09.2026).

Работа делится на **два независимых этапа**:

- **Этап 1 — вёрстка (сейчас).** Чистая адаптивная вёрстка HTML/CSS/JS всех экранов
  по PSD, на демо-данных. Без бэкенда, оплаты и импорта. Папка `02_верстка/`.
- **Этап 2 — натяжка на WP (отдельно, позже).** WordPress+WooCommerce, товары с
  вариантами, импорт 24 196 цветов, серверные расчёты, оплата Сбербанк + фискализация,
  заказы, роли, перенос на хостинг и запуск. Оценивается отдельно.

## Как открыть

Открыть `02_верстка/index.html` в браузере. Все страницы — заготовки: каркас HTML,
подключённые CSS/JS и комментарий с привязкой к макету и пункту ТЗ. Разметку экранов
наполняем по PSD из `01_исходники/макеты_psd/`.

## Ключевые особенности (что делает магазин непростым)

- **Каталог цветов**: 28 палитр, 24 196 оттенков (RGB/HEX). Плашки цвета, поиск по коду.
- **Визуализатор**: 4 сцены интерьера (гостиная/кухня/детская/ванная), перекраска стены
  по маске с сохранением фактуры и тени.
- **Колеровка и пробник 300 мл**: подбор цвета к товару, доплата за колеровку.
- **Товары с вариантами** (фасовки), корзина, оформление, оплата, счёт для юрлиц/ИП.

Полный текст требований — в `00_ТЗ/`.

## Стек вёрстки

Чистые **HTML5 / CSS3 / JavaScript** без сборщика и фреймворков. Mobile-first.
Проверяемые ширины: **360 / 390 / 768 / 1024 / 1440 / 1920 / 2560**.
Токены (цвета/шрифты/отступы) — в `02_верстка/css/variables.css`, снимаются из PSD.

## Сверка с макетами (важные уточнения)

**Макетов 25, страниц 25.** Эталон раскладки — композиты из PSD:
`psd-extract/spec/<имя>/composite.png`, по одному на каждый экран.

Папка `01_исходники/макеты_png` содержит **24 PNG**, и по ней сверяться нельзя целиком:

| Что не так | Факт |
|---|---|
| `Выбор цвета и визуализатор.png` | внутри **не визуализатор**, а сетка оттенков F316 (устаревший дубль «Список оттенков»). Настоящий макет — только composite; `pages/visualizer.html` свёрстан по нему |
| `Заменяется безопасным сценарием оплаты.png` | это модалка «Реквизиты для оплаты» с полем «Номер карты», а не страница. **Макета страницы «Оплата» (М24) не существует**; она свёрстана по ТЗ п. 8.3 (ввод карты на сайте запрещён, оплата через шлюз) |
| `Селектор палитры.png` | фрагмент — только выпадающий список каталогов |
| `Подтверждение добавления товараpsd.png` | модальное окно 916×677 без подложки страницы |
| `Уведомление и настройки cookie.png` | полоса 2708×305 |
| `Реквизиты для счёта.png` | модалка «Реквизиты юридического лица» |
| М18 «Четыре интерьерные сцены» | PNG нет вообще — это 4 ассета для визуализатора, своего URL не имеет |

Подробный разбор с размерами, картой «код → макет → файл» и порядком сверки —
**`02_верстка/СВЕРКА_С_МАКЕТАМИ.md`**.

**Проверять глазами:** `02_верстка/screens.html` — одна страница, где для каждого из 25 экранов
слева стоит макет, справа кнопка «Открыть вёрстку». Страница служебная: `noindex`,
**из сайта не линкуется**, открывается только по прямому адресу `…/screens.html`.
Картинки макетов для неё лежат в `02_верстка/assets/mockups/М01.jpg … М25.jpg`.

## Шрифты

Montserrat (400/500/600) и Open Sans (400/600) — self-host, кириллица + латиница, покрывают ≈ 91 % текста.
Номера «01–09» набраны **Tinos** — свободным метрическим клоном Times New Roman (Apache 2.0):
сам Times вшивать нельзя, а на Android/Linux его нет, из-за чего раньше подставлялась Georgia
с «старыми» цифрами. Расхождение метрик с макетом — ноль.

**Sovest** (в макетах им набраны только цифры: телефон, счётчик корзины, пагинация) в исходниках
отсутствует и в свободном доступе не найден — эти места набраны Montserrat, расхождение по ширине
−2 %, визуально неотличимо. Если у заказчика есть файлы и веб-лицензия — подключаются за 15 минут.

Подробный разбор, лицензии и варианты решения — **`02_верстка/FONTS.md`**.

## Публикация

Сайт лежит в `02_верстка/`. На Vercel задайте **Settings → General → Root Directory = `02_верстка`**
и сделайте Redeploy — иначе на «/» будет 404. Подробности и альтернативы — в `DEPLOY.md`.
В корне добавлен страховочный `index.html` с редиректом.
