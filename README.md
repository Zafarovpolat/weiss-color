# Weiss Color — проект интернет-магазина

Интернет-магазин красок, лаков и пропиток **Weiss Color** на WordPress + WooCommerce.
Продавец — ООО «Фаер Гвард». Субподряд через агентство (RUSO, договор №24 от 17.09.2026).

Работа делится на **два независимых этапа**:

- **Этап 1 — вёрстка (сейчас).** Чистая адаптивная вёрстка HTML/CSS/JS всех экранов
  по PSD, на демо-данных. Без бэкенда, оплаты и импорта. Папка `02_верстка/`.
- **Этап 2 — натяжка на WP (отдельно, позже).** WordPress+WooCommerce, товары с
  вариантами, импорт 24 196 цветов, серверные расчёты, оплата Сбербанк + фискализация,
  заказы, роли, перенос на хостинг и запуск. Оценивается отдельно.

## Как открыть

Открыть `02_верстка/index.html` в браузере. Все страницы — заготовки: каркас HTML,
подключённые CSS/JS и комментарий с привязкой к макету и пункту ТЗ. Разметку экранов
наполняем по PSD из `01_исходники/макеты_psd/`.

## Ключевые особенности (что делает магазин непростым)

- **Каталог цветов**: 28 палитр, 24 196 оттенков (RGB/HEX). Плашки цвета, поиск по коду.
- **Визуализатор**: 4 сцены интерьера (гостиная/кухня/детская/ванная), перекраска стены
  по маске с сохранением фактуры и тени.
- **Колеровка и пробник 300 мл**: подбор цвета к товару, доплата за колеровку.
- **Товары с вариантами** (фасовки), корзина, оформление, оплата, счёт для юрлиц/ИП.

Полный текст требований — в `00_ТЗ/`.

## Стек вёрстки

Чистые **HTML5 / CSS3 / JavaScript** без сборщика и фреймворков. Mobile-first.
Проверяемые ширины: **360 / 390 / 768 / 1024 / 1440 / 1920 / 2560**.
Токены (цвета/шрифты/отступы) — в `02_верстка/css/variables.css`, снимаются из PSD.
