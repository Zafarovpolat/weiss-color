# Публикация (Vercel)

## Почему было «Page doesn't exist»

Репозиторий устроен так, что сайт лежит не в корне, а в папке `02_верстка/`:

```
weiss-color/
├── 00_ТЗ/
├── 01_исходники/
├── 02_верстка/      ← здесь index.html, pages/, css/, js/, assets/
└── README.md
```

Vercel по умолчанию ищет `index.html` **в корне** и, не найдя, отдаёт 404 на «/».

## Вариант 1 (рекомендуется): Root Directory = 02_верстка

1. Vercel → проект → **Settings → General → Root Directory** → `02_верстка` → Save
2. **Deployments → ⋯ → Redeploy** (обязательно, после смены настройки)

После этого сайт открывается сразу с главной.

## Вариант 2: корневой редирект (уже добавлен)

В корне лежит `index.html`, который переадресует на `02_верстка/index.html`.
Работает без настроек, но URL получается вида `.../02_верстка/pages/catalog.html`.

## Третий вариант: отдельный репозиторий

Если нужен чистый корень — сделать репозиторий, где содержимое `02_верстка/`
лежит в корне. Так не будет ни редиректа, ни префикса в URL.

## Прочее

- Framework Preset: **Other**, Build Command: пусто, Output Directory: пусто.
- `vercel.json` в корне задаёт кэширование `assets/*` на год.
- Внутренние ссылки относительные (`../pages/...`), поэтому сайт одинаково
  работает и на Vercel, и локально через `python3 -m http.server`.
